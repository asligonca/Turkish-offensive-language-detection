# Turkish offensive-language seed lexicon
# Format:
#   - one term per line, lowercase
#   - a line starting with "#" sets the category for the terms below it
#     (the first lines here are just comments; the last "#" line before a
#     term is its category)
#   - a trailing "$" means whole-word only: use it for short or ambiguous
#     terms (e.g. "göt$" so that "götürmek" doesn't match)
#   - without "$" a term also matches with suffixes (şerefsiz -> şerefsizler)
#   - multi-word phrases are fine ("mal herif")
#   - matching ignores case, apostrophes, leetspeak (s1kt1r), dots/spaces
#     between single letters (a.q, o.ç) and stretched letters (siktirrrr)
#
# Precision notes (every hit marks a post "offensive_candidate"):
#   - ASCII spellings (serefsiz, amcik ...) are listed explicitly. The matcher
#     does NOT fold ı->i, because then "sık sık" / "sıkıntı" would hit "sik...".
#   - Words with a common harmless meaning only appear as phrases:
#     mal (goods), alçak (low), pislik (dirt), ezik (crushed), aşağılık
#     (aşağılık kompleksi), boynuzlu (horned animal).
#   - Deliberately left out: lan/ulan (filler), kaşar (cheese), top (ball),
#     dönme, bare "sik", and neutral identity words (ethnicities, religions,
#     nationalities): those would flag neutral posts and bias the model.
#
# This is a SEED list. Extend it for your project; keyword hits are weak labels.
